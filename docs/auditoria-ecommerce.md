## Criterios de aceptación

- Persona nueva reconoce qué se vende, cómo buscar y dónde comprar en una observación breve. La meta de cuatro segundos requiere prueba con personas; no se presenta como garantía.
- Recorrido principal de 4–5 transiciones como máximo desde elegir producto hasta registrar pedido invitado. Contar por separado escritura, selección de variante/dirección y transferencia bancaria externa; registrar pedido no significa haber pagado.
- Carrusel superior: intervalo inicial de 8 segundos, pausa explícita, pausa al enfocar/interactuar, respeto de movimiento reducido, controles con teclado y avance manual. Siguiente tarjeta parcialmente visible; ninguna foto queda permanentemente inaccesible.
- Recomendaciones por uso con productos reales; campañas de temporada/lanzamiento solo con datos editoriales confirmados.
- Búsqueda visible, filtros reversibles, disponibilidad, orden correcto en todo el catálogo, errores recuperables y estados vacíos claros.
- Ficha con precio, variante, stock, galería navegable y descripción disponible. Información nutricional con su porción; no sustituir datos faltantes por promesas inventadas.
- Referencia WCAG 2.2 AA: texto normal 4,5:1, texto grande 3:1, controles/foco distinguibles; objetivo táctil de diseño 44 px, reflujo móvil y teclado.
- Objetivo de carga: menos de 3.000 ms. Medir build de producción, dispositivo/red declarados, contenido visible y recursos. Pendiente p75 real de producción; una medición local no lo certifica.

## Flujo y presupuesto de acciones

| Entrada | Transiciones para registrar pedido |
| --- | --- |
| Portada, producto con variantes | 1. Explorar productos → 2. Elegir opciones → 3. Agregar al carrito → 4. Datos de entrega → 5. Confirmar pedido. |
| Producto recomendado con variantes | 1. Elegir opciones → 2. Agregar al carrito → 3. Datos de entrega → 4. Confirmar pedido. |
| Catálogo, producto de una presentación | 1. Agregar → 2. Datos de entrega → 3. Confirmar pedido. |

Esto cuenta transiciones, **no todos los clics físicos**: cambiar sabor, escribir dirección, corregir datos o elegir envío requiere acciones adicionales. La transferencia bancaria sucede fuera de la tienda y no está completada al registrar el pedido. Por tanto, no se afirma que una compra nueva se pague con cinco clics totales ni en cuatro segundos.
